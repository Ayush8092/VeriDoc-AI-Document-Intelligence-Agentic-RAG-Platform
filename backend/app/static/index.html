Veridoc

This is the backend API, running standalone. The full product UI — chat, document library, upload — is the Next.js app in ../frontend (see its README to run it); this page is just a dependency-free fallback for hitting the API directly.

API surface:

  • /docs — interactive API docs (Swagger UI)
  • GET /health, GET /ready
  • POST /ask
  • POST /documents/upload, GET /documents
